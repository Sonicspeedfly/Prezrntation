## Коротко

Подсистема отвечает за всё, что Элис и Нейкон говорят записанным голосом. Ведущий открывает студию (`studio.html`, только на машине с `serve.js`), записывает реплику с микрофона или прикладывает файл, правит текст; сервер кладёт файл в `assets/voice/<язык>/<id>.<ext>`, пересобирает манифест `VOICE_CLIPS` и, для длинных дорожек, субтитры `JURY_CUES`. Открытая презентация подтягивает это без перезагрузки (`voiceSync()`). Длинные дорожки — пять актов интро для жюри, тест голоса в настройках и пасхалку «Взаперти» — играет `VoiceMedia`; интро (`JuryIntro`) перехватывает экран загрузки на 24 %, печатает субтитры того языка, который реально звучит, и переключает сцены по репликам сценария. Перед раздачей с флешки студия вшивает все записи в манифест как base64.

### Данные и форматы

**Каталог `voice/catalog.json`.** Верхний уровень: `about` (пояснение для человека), `stretch` (правило про дефис внутри слова — «Пра-вильной»: голос заедает на слоге; студия показывает его над списком, спикер-лист — в начале), `lines` — массив из 29 записей. Текста в каталоге нет, только режиссура:

| поле | где есть | смысл |
|---|---|---|
| `id` | все | имя записи и ключ во всех таблицах: `deck.slide01…05`, `deck.bg01…11`, `demo.*`, `jury_act1…5`, `voice_test`, `secret_locked` |
| `system` | все | `deck` (16), `demo` (6), `media` (7) — откуда берётся текст и как подменяется звук |
| `group` | deck, media | `story` (5) / `bg` (11); `jury` (5) / `extra` (2) |
| `key` | demo | ключ строки в `STRINGS` (`10-i18n.js`) |
| `who`, `label`, `where`, `emotion`, `pace`, `note` | все / по желанию | режиссура для карточки и спикер-листа |
| `reachable` | demo | `false` у `demo.solved.medium`, `demo.solved.easy`: на этой сложности голос выключен, студия пишет «сейчас не звучит» |

**Где живёт текст.** Каталог текст не хранит (`voice/lib.js`, шапка): русский текст дека — строка `text:` в `js/presentation/08-alice-lines.js` (`ALICE_STORY_LINES.SLIDE_NN`, `ALICE_BG_LINES[N-1]`); перевод дека — `VOICE_TEXT`; текст демки — `STRINGS[loc][key]` в `10-i18n.js`; текст длинной дорожки — раздел сценария `voice/scripts/<loc>.txt`.

**Сценарий `voice/scripts/<loc>.txt`.** Четыре файла (`ru`, `en`, `tj`, `tj_col`), в каждом пять разделов `## jury_act1…5` (в `tj_col.txt` акт 5 стоит перед актом 4 — порядок разделов не важен). Формат:

```
# комментарий (строка с одного #)
## jury_act1
ЭЛИС: (тег голоса) Текст первой реплики. Ещё фраза.
НЕЙКОН: (тег) Текст второй реплики.
```

Одна строка — одна реплика (turn); говорящий — `НЕЙКОН`/`NEIKON` или `ЭЛИС`/`ELIS`/`ALICE`, регистр не важен (во всех четырёх файлах сейчас кириллица). Всё в `(скобках)` — теги ElevenLabs, в субтитры не попадают. Порядок реплик обязан совпадать с записью: по нему ищутся передачи слова. Реплик на акт: 2, 3, 3, 2, 2 (Э-Н, Н-Э-Н, Н-Э-Н, Э-Н, Н-Э).

**Штампы `voice/stamps.json`.** `{ <loc>: { <id>: "<первые 12 hex sha1 показанного текста>" } }`. Пишет `stamp()` при сохранении записи и по кнопке «запись верная», стирает `unstamp()` при удалении. Сейчас по 23 штампа у `en`, `tj`, `tj_col`; у `ru` записей из студии нет.

**`VOICE_CLIPS`** (`00-voice-clips.js`, генерирует `writeManifest()`): `{ <loc>: { <id>: <src> } }`, только локали, где есть хоть одна запись, id отсортированы. Два режима, режим записан в шапке строкой `Mode:` и по ней же определяется (`manifestIsInline()`):

| режим | `src` | когда |
|---|---|---|
| пути | `assets/voice/<loc>/<file>?v=<mtime в мс>` | обычный: файл мал (сейчас 69 записей на 25.33 МБ звука — сам файл 6 КБ), студия меняет записи на лету |
| вшитый | `data:<mime>;base64,…` | «вшить записи (для флешки)»: работает с `file://`, весь звук внутри скрипта |

Сейчас: `en`, `tj`, `tj_col` × 23 (16 реплик дека, 5 актов, `voice_test`, `secret_locked`), режим путей. Файлы в `assets/voice/<loc>/`, имя которых не id из каталога, в манифест не попадают — `writeManifest()` возвращает их в `unknown`, `serve.js` печатает при старте.

**`VOICE_TEXT`** (`00-voice-text.js`, генерирует `writeVoiceText()`): `{ <loc>: { <deck id>: "перевод" } }` — только реплики дека и только не-русские локали. Сейчас `en`, `tj`, `tj_col` × 16. Ключи упорядочены по каталогу.

**`JURY_CUES`** (`14-jury-cues.js`, генерирует `voice/cues.js` → `writeOut()`):

```
JURY_CUES[loc][trackId] = {
  dur:   30.16,                                   // с, длина разобранного звука
  turns: [ { who: "alice"|"neikon", start, end } ],   // реплики сценария по порядку
  cues:  [ { t, who, block, text, end } ]          // фразы; block — индекс реплики в turns
}
```

Сейчас 4 локали × 5 актов, по 39 фраз на локаль (9, 10, 9, 6, 5), всего 156. Время в секундах, два знака. `text` — сценарий дословно без тегов.

### Что звучит и что показывается

| система | звук | текст |
|---|---|---|
| дек (`09-alice-stream.js`) | своя запись `VOICE_CLIPS[loc][id]` → вшитая русская, **только пока субтитр русский** → ничего | `VOICE_TEXT[loc][id]` → русский `p.text` |
| демка (`03-alice-voice.js`) | своя запись → синтез браузера (на HARD) | `STRINGS[loc][key]` |
| длинная дорожка (`VoiceMedia`) | своя запись → она же по голому пути (повтор) → русская запись `assets/voice/ru/` (и её повтор) → `assets/audio/ru/<id>.mp3` → `assets/audio/ru/masters/<id>.mp3` | субтитры интро — `JURY_CUES[язык, который звучит]` |

Короткие реплики не падают на чужой язык: русский голос под таджикским субтитром хуже тишины. Длинные — падают на русский, а интро тогда показывает русские субтитры. Студия показывает то же правило меткой карточки (`plays` из `listing()`): `own`, `baked`, `synth`, `none`.

### Студия: от микрофона до игры

1. Старт. Страница с `file://` сразу говорит «запустите start.bat» (`offline()`). Иначе `GET api/voice/info`: если `local` ложно — «только на компьютере, где запущен сервер». Иначе язык выбирается из `?loc=`, `localStorage["ts.studio.locale"]`, `ru` — первый существующий; рисуются панели, `load()` берёт карточки `GET api/voice/lines?loc=`.
2. Карточка (`cardHtml()`): id, говорящий, где звучит, метки «сейчас не звучит» и «⚠ текст менялся после записи», метка состояния; поле текста; для дека на чужом языке — русский оригинал; для длинной дорожки на чужом языке — русский сценарий; поле «читать» (кроме `media`); режиссура; кнопки.
3. Запись: `record()` — `getUserMedia` (эхоподавление и АРУ выключены, шумоподавление включено), `MediaRecorder` с первым поддержанным из `audio/webm;codecs=opus`, `audio/ogg;codecs=opus`, `audio/webm`, `audio/mp4`, 128 кбит/с, куски по 200 мс; индикатор пика и секундомер на `requestAnimationFrame`. Стоп → `Blob` → `setTake()`.
4. Файл: `attach()` — расширение по MIME или имени (`extOf()`), не больше 25 МБ, затем пробный `<audio preload="metadata">`: не открылся — файл отвергается («значит, и игра не сможет»). Иначе `setTake()` и длина в секундах.
5. Несохранённый дубль живёт в `state.takes[id]` как `blob:` URL с плеером, «скачать», «выбросить».
6. «Сохранить в игру» — `saveTake()`: `POST api/voice/take/<loc>/<id>`, тело — сам blob, `Content-Type` по расширению. Сервер: `lib.saveTake()` → `retime()`. Ответ несёт итог пересборки субтитров; `reload(id)` перерисовывает одну карточку, `cueNote()` пишет, сколько фраз и реплик получилось или почему не вышло.
7. Текст — `saveText()` (кнопка или Ctrl+Enter): `POST api/voice/text/<loc>/<id>` с `{ text }` → `lib.setText()`; для `media` тоже `retime()`. Студия честно пишет, когда правку увидит открытая презентация: перевод дека — при смене языка (он в `VOICE_TEXT`), русский дек и демка — после перезагрузки (статические файлы `08-alice-lines.js`, `10-i18n.js`).
8. Штамп: если текст поменяли после записи, `listing()` ставит `stale`; «запись верная» — `POST api/voice/stamp/<loc>/<id>`.
9. Удаление: `POST api/voice/take/<loc>/<id>?delete=1` после `confirm()`.
10. Выгрузка: «скачать спикер-лист» — ссылка на `api/voice/script?loc=` (Markdown из `renderScript()`); панель «Скачать аудио» — ссылка на `api/voice/pack?…` (ZIP из `packEntries()` + `zip()`).
11. «Вшить записи (для флешки)» / «вернуть пути» — `POST api/voice/manifest?inline=1|0` → `writeManifest({ inline })`. Режим сохраняется: каждое следующее сохранение записи пересобирает манифест в том же режиме.

### Тексты: как `voice/lib.js` пишет в исходники

`setText(loc, id, raw)` нормализует переводы строк, обрезает пробелы и выбирает путь по `line.system`:

| система | `ru` | другие языки | пусто |
|---|---|---|---|
| `deck` | `patchDeckRu()` — одна строка `text:` в `08-alice-lines.js` | `patchVoiceText()` → `writeVoiceText()` переписывает `00-voice-text.js` целиком | `ru` — 400; иначе перевод удаляется |
| `demo` | `patchStrings()` — одна строка `"key": value` в блоке языка `10-i18n.js` | то же | 400 (пустой субтитр) |
| `media` | `checkScript()` → `writeScriptSection()` — раздел `## id` в `voice/scripts/<loc>.txt` | то же | `ru` — 400 (база субтитров); иначе раздел удаляется |

Неизменённый текст русского дека, демки и сценария файл не трогает; перевод дека переписывает `00-voice-text.js` при каждом сохранении. `patchDeckRu()` находит строку по позиции (блок `SLIDE_NN` или N-я строка `text:` после `ALICE_BG_LINES`) и перед записью сверяет её раскодированное содержимое с тем, что вернул `deckEntry()`; не совпало — 500, файл не тронут. `patchStrings()` требует, чтобы ключ встретился в блоке языка ровно один раз. Остальные байты файла сохраняются, выравнивание колонок тоже.

Чтение исходников без браузера: `evalGlobals()` оборачивает файл в функцию и выполняет его в `vm.runInNewContext` с заглушкой DOM (`shim()`), возвращая объявленные `const`. Результат кешируется по `mtime`+`size` (`cached()`): правка из студии, из командной строки или в редакторе подхватывается при следующем чтении.

### Субтитры из сценария: алгоритм `voice/cues.js`

Распознавания речи нет: текст — сценарий слово в слово, из звука берётся только время.

1. **Сценарий.** `parseScript()` → `{ id: [ { who, text, sentences } ] }`. `clean()` выбрасывает `(теги)` и пробелы перед знаками препинания. `sentences()` режет после `. ! ? …`, только если следующее слово начинается с заглавной (латиница, кириллица, таджикские `ӢӮҒҚҲҶ`) или с кавычки: «Нейкон... взгляни» остаётся целым, «из зала... Это» делится. Неизвестный говорящий — исключение.
2. **Звук.** `audioFor(loc, id)`: запись из студии этого языка; для `ru` без записи — `assets/audio/ru/<id>.mp3` (веб-копия, её слышит зал), потом `assets/audio/ru/masters/<id>.mp3`. Для другого языка без записи — `null`: раздел пропускается и удаляется из `JURY_CUES`, интро сыграет русскую запись с русскими субтитрами.
3. **Декодирование.** `decode()` — `ffmpeg -ac 1 -ar 16000 -f f32le` в `Float32Array`.
4. **Кадры.** `frames()`: окно 480 отсчётов (30 мс), шаг 320 (20 мс). Энергия в дБ; ниже `SILENCE_DB` = −38 — тишина. Для звучащего кадра — основной тон автокорреляцией по лагам 40…228 (400…70 Гц); принимается, если нормированная корреляция > 0.55, иначе `f0 = 0` (шёпот, шум).
5. **Паузы.** `gaps(fr, 0.12)` — отрезки тишины от 0.12 с, только внутри речи (между первым и последним звучащим кадром).
6. **Передачи слова.** Для каждой границы k между репликами:
   - ожидаемое время — доля символов: `expected = spanStart + spanLen · Σchars[0..k] / Σchars`;
   - окно поиска `W = max(4 с, 0.25 · spanLen)`, `lo = max(prev + 0.8, expected − W)`, `hi = min(spanEnd − 0.8, expected + W)`;
   - кандидаты — середины пауз в окне плюс каждые 0.1 с окна (передача без паузы);
   - `windowStats()` по 3 с до и после кандидата (медиана f0 при ≥ 5 тональных кадрах, доля тональных кадров);
   - оценка = `pitch + voicing + near + pause`:
     - `pitch = dir · log2(f0_после / f0_до)`, `dir = +1`, если дальше говорит Элис (голос выше: Milly около 210 Гц), `−1` — если Нейкон (Egor около 130 Гц);
     - `voicing = dir · (тональность_до − тональность_после) · 0.5` — Элис шепчет в первом и последнем актах, у шёпота нет тона;
     - `near = −|t − expected| / W · 0.35`;
     - `pause = 0.15 + min(длина паузы, 0.6) · 0.3`, если кандидат — пауза;
   - лучший кандидат становится границей и левым краем окна следующей.
7. **Фразы внутри реплики.** Первая фраза — начало реплики. Для j-й: доля символов предыдущих фраз переводится в индекс среди **звучащих** кадров реплики (паузы не считаются), затем время притягивается к ближайшему началу речи (концу паузы) в пределах 0.6 с внутри реплики.
8. **Конец фразы** — начало следующей, у последней — конец речи. Если две фразы притянулись к одной точке, следующая сдвигается на +0.25 с: время строго растёт.
9. **Запись.** `rebuild()` читает существующий `14-jury-cues.js` (`readExisting()`), заменяет только свою локаль (или один трек), удаляет разделы, которых нет в сценарии, и переписывает файл (`writeOut()`). Возвращает отчёт по трекам — `retime()` в `serve.js` превращает его в `{ ok, phrases, turns }` или `{ ok: false, why }`.

Командная строка: `node voice/cues.js [loc] [--debug]` — печатает реплики с тоном и звонкостью, с `--debug` ещё каждую границу (ожидалось/выбрано, вклад pitch/voicing/pause) и фразы.

### `VoiceMedia`: одна дорожка от запроса до конца

1. `play(id, opts)` строит список источников `sources(id)` (см. таблицу выше; каждый — `{ url, loc }`), берёт `VoiceBus` как «sample» (с `interrupt`, если не запрещено), поднимает `hold` (`window.__voiceMediaHold = true`), кладёт ручку в `active` и зовёт `tryNext()`.
2. `tryNext()` берёт следующий источник. Если `preload()` уже качает именно этот URL — берёт тот элемент (буфер не теряется); если качает другой (старый язык) — обрывает его `drop()`. Ставит обработчики, маршрутизирует `route()` и зовёт `play()` элемента.
3. Ошибка загрузки до старта → следующий источник. `NotAllowedError` у `play()` (нет жеста пользователя) → `onError` сразу, без перебора: виноват браузер, не файл. Обрыв после старта → `onError("обрыв …")`.
4. Первый `playing` → `onStart({ loc, duration })`: вызывающий узнаёт, какой язык реально звучит.
5. `route()`: по http — `MediaElementSource` (создаётся один раз на элемент, хранится в `el.__vmSrc`) → анализатор (`fftSize` 512, сглаживание 0.6) → усиление → голосовая шина `Audio.getVoiceNode()` (бус `voice`) или `ctx.destination` с громкостью мастера (бус `master`, опрос каждые 200 мс). С `file://` или если `AudioContext` не в состоянии `running` — элемент играет сам, громкость `trim × busVolume(bus)` опрашивается каждые 200 мс.
6. `ended` → `finish("end")` → `onEnd`. `finish` один раз: снимает граф и опрос, убирает из `active`, опускает `hold`, отпускает `VoiceBus`, зовёт колбэк.
7. Смена языка на ходу: `followAll()` → `follow()` у каждой ручки с `followLocale`. Новый первый источник отличается от текущего → запоминается доля `currentTime / duration`, тому же элементу ставится новый `src`, по `loadedmetadata` — та же доля новой длины. Граф Web Audio переживает смену `src`. Не загрузилось — `switching` разрешает `onerror` идти вниз по новому списку.

### `JuryIntro`: пять актов

```
DOMContentLoaded +600 мс ─ prime() ─ preload(jury_act1), __juryIntroHoldsLink = true
                              │       canplaythrough | error | 9 с → idle() → releaseLink() → loadAliceAudio()
applyLocale() ─ prime() ──────┘  (новый язык: старый недокачанный акт 1 обрывается)

runLoadingSequence (11-settings), 24 % ─ JuryIntro.run(hooks) = start()
  build() → .ji в body; __juryIntroHoldsLink = true; Audio.stopMusic()
  через 1100 мс (calm: 400) ─ nextAct()
     ┌─ act++ ; ≥ 5 → armEnter()
     │  stagingFor(r, act); watchdog каждые 500 мс; VoiceMedia.play(ACTS[act])
     │    onStart: cuesFor(id, info.loc, duration) → r.cues, r.marks; preload(следующий акт);
     │             акт ≥ 4 → releaseLink()
     │    loop() на rAF: fireCue() для каждой фразы с t ≤ now + 0.05 — строка субтитра,
     │             «▶ говорящий», сцены этой реплики; печать текста; эквалайзер

     └──────────────────────────────────────────────────────────────────┘
  исходы finish(): "enter" (Enter/пробел/клик по кнопке, когда armed) → дек через kernel panic
                   "skip" (ESC, кнопка пропуска, abort()) → panic()
                   "unavailable" (акт 1 не начался) → загрузчик продолжает с 24 %
```

**Сторож загрузки** (`watch` внутри `nextAct()`): раз в 500 мс смотрит `buffered()` текущего элемента. Если буфер растёт — ждём; после 2.5 с в строке статуса виден процент (`loaded()`). Акт пропускается, если буфер не двигался `ACT_STALL_MS` = 15 с или акт не начался за `ACT_MAX_WAIT_MS` = 90 с. Причина пишется в `lastWhy` (`"jury_act2 stalled at 37%"`), загрузчик показывает её как `JuryIntro.why`. Пропуск акта 1 = `finish("unavailable")`: ничего не сыграло, интро отдаёт экран загрузчику.

**Субтитры** (`cuesFor()`): есть `JURY_CUES[loc][id]` для языка, который звучит, — фразы как есть, с текстом. Нет — берутся русские фразы, время умножается на `duration / ru.dur`, текст не показывается (`ji-notext`): сцены идут, субтитров нет.

**Постановка** (`stagingFor()`): список `{ turn, at, fn }`, `at` — `start` (первая фраза реплики), `last`, `penult`. `indexTurns()` для каждой фразы вычисляет `first/last/penult` внутри её реплики; `fireCue()` запускает каждую сцену один раз.

### `VoiceExtras`: тест голоса и «Взаперти»

**Тест голоса.** `11-settings.js` после каждой отрисовки попапа зовёт `mount(body, tab)`. На вкладке «audio» под ползунком `volVoice` вставляется блок `.vt`: кнопка, 24-сегментный индикатор, строка лога. `startTest()` играет `voice_test` по шине `voice` с `followLocale`; `loopTest()` на rAF рисует уровень (`h.level()`), пиковую метку с затуханием ×0.94 за кадр, свечение ползунка (`--vt-level`), строку `[ EN ] 00:07 / 00:21 · уровень −18 dBFS`. Попап пересобирается при каждом переключении — идущий тест не перезапускается, а показывается в новых элементах (`liveUi()`). Другая вкладка или закрытие попапа — `stopTest()`.

**«Взаперти».** Два скрытых входа: три клика по `.alice-core-mark` за 700 мс; ползунок голоса в 0 % с зажатым Shift (один раз на каждый спуск в ноль, флаг `armed`). Третий — плитка в служебном доступе (`21-backstage.js` → `fireSecret("panel")`). `fireSecret()`: останавливает тест, ставит `ts.secret.locked`, вспышка `SAFE MODE · REG 0x00` на 520 мс (в спокойном режиме — затухание), глитч, тост со счётчиком и кнопкой стоп; через 480 мс — `secret_locked` по шине `master` (второй вход только что обнулил голосовую), с `followLocale`. Конец, ошибка или «■» — `stopSecret()`.

## Почему так, а не иначе

- **Ключ записи — стабильный id, а не текст реплики.** Очевидно было бы искать запись по строке. Но строку правят: первая же правка опечатки потеряла бы запись (ARCHITECTURE, «Озвучка»). Чтобы при этом голос и субтитр не разошлись молча, сервер хранит хеш текста на момент записи (`stamp()`, `voice/stamps.json`), а `listing()` сравнивает его с текущим и ставит `stale` — студия показывает «⚠ текст менялся после записи».
- **Текст не копируется в каталог.** Каталог держит только режиссуру, текст правится в том файле, откуда его читает игра (`08-alice-lines.js`, `00-voice-text.js`, `10-i18n.js`, `voice/scripts`). Вторая копия устарела бы при первой правке в другом месте (шапка `voice/lib.js`). Цена — точечная правка чужих исходников: поэтому `patchDeckRu()` сверяет найденную строку с текущим содержимым и отказывается писать, если файл устроен не так, как ожидалось, а `patchStrings()` требует ровно одно вхождение ключа.
- **Запись на каждый язык своя; на русский падают только длинные дорожки.** Короткая реплика дека без записи на этом языке идёт текстом (или русской вшитой записью, пока и субтитр русский): русский голос под таджикским субтитром хуже тишины (`voice/README.md`, `voiceSrcFor` в `09-alice-stream.js`). Акт интро длится от 13 до 60 секунд, а всё интро — около трёх минут: молчание перед жюри хуже русского голоса (комментарий в `listing()`). Поэтому `VoiceMedia.sources()` всегда заканчивается русскими файлами.
- **Субтитры — того языка, который звучит, а не языка интерфейса.** `VoiceMedia` сообщает язык в `onStart({ loc })`, `JuryIntro` по нему выбирает `JURY_CUES[loc]` и имена говорящих (`speaker()`): русская запись под английским интерфейсом идёт с русским текстом и «НЕЙКОН:». Перевод поверх чужого голоса читался бы как ошибка. С той же целью `voice/cues.js` не строит субтитры для переведённого сценария без записи — иначе интро показало бы их поверх русской речи.
- **Сцены привязаны к репликам, а не к секундам.** Записи на разных языках разной длины (акт 2: 53.94 с по-русски, 60.26 с по-таджикски), перезапись меняет темп. Сцена «на последней фразе реплики Нейкона» попадает в нужное место на любом языке и после любой перезаписи; требование одно — тот же порядок реплик в переводе (`stagingFor()`, шапка `16-jury-intro.js`). Для записи без сценария постановку держат русские тайминги, растянутые на длину записи (`cuesFor()`).
- **Время фраз — из звука, текст — из сценария, без распознавания речи.** Распознаватель угадывал бы слова; сценарий даёт точный текст и порядок говорящих, звук — только моменты. Нужен один ffmpeg; без него студия по-прежнему сохраняет записи и тексты и пишет, что субтитры не пересобраны (`hasFfmpeg()`, `retime()` в `serve.js`).
- **Граница реплик — по сумме признаков, а не по порогу высоты.** Фиксированный порог ломается: ироничная подача Egor поднимается за 200 Гц, и целые куски акта 2 уходили бы Элис; шёпот Элис в актах 1 и 5 не имеет тона вовсе. Поэтому оценка складывает смену тона в нужную сторону, смену звонкости, близость к месту, ожидаемому по числу символов, и бонус за паузу (шапка `voice/cues.js`).
- **Фразы раскладываются по времени речи, без пауз, и притягиваются к началу звука.** Доля символов от полной длины реплики сдвигала бы фразы на длину пауз; притяжение к ближайшему началу речи в пределах 0.6 с ставит субтитр туда, где голос действительно начал фразу.
- **Два режима манифеста: пути и base64.** Пути дают файл в 6 КБ, а студия меняет запись на лету; `?v=<mtime>` в пути заставляет браузер взять новый дубль с тем же именем вместо кешированного (комментарий у `clipTable()`). Но `index.html`, открытый двойным щелчком, может не отдать звук по относительному пути — для флешки все записи вшиваются в `00-voice-clips.js`. `writeManifest()` без явного `inline` сохраняет текущий режим, чтобы сохранение записи не отменило молча сборку для флешки. `GET /api/voice/manifest` при этом всегда отдаёт пути: запись, сохранённая секунду назад, должна играть сразу.
- **Таблицы перезаполняются на месте, а не переприсваиваются.** `VOICE_CLIPS`, `VOICE_TEXT`, `JURY_CUES` — `const` в общей области классических скриптов (см. [README.md](README.md)); переприсвоить их нельзя, а читатели обращаются к ним по имени в момент вызова. `voiceSyncRefill()` чистит ключи и копирует новые. С `file://` или чужого сервера запрос падает молча, и в силе остаются сгенерированные файлы — ровно поведение без сервера.
- **Синхронизация по событиям, а не опросом.** `voiceSync()` срабатывает при загрузке, при возврате на вкладку и при смене языка. Новая запись нужна именно тогда, когда ведущий вернулся из студии во вкладку или переключил язык (шапка `00-voice-sync.js`). По коду видно, что опроса по таймеру нет; вероятно, чтобы не тратить канал телефонов жюри.
- **Длинная дорожка идёт через Web Audio, кроме `file://`.** Через граф голосовая шина и ползунок громкости работают вживую, а анализатор даёт настоящий уровень и спектр для эквалайзера интро и индикатора теста. Chrome считает локальный файл другим источником, и `MediaElementSource` с `file://` выдаёт тишину — там элемент играет сам, громкость опрашивается, а `level()` рисует правдоподобную огибающую речи (шапка `15-voice-media.js`).
- **«Взаперти» — на шине мастера.** Второй вход в пасхалку — ползунок голоса в ноль; на голосовой шине её бы не было слышно (шапка `18-voice-extras.js`, `note` в каталоге).
- **Смена языка на ходу — с той же доли, а не с той же секунды.** Дубли на разных языках разной длины; 20-я секунда из 30 — это две трети, а не 20-я секунда из 40 (`follow()`). Интро языку не следует: его субтитры и постановка рассчитаны по языку, на котором акт начался.
- **Сторож следит за ходом загрузки, а не за часами.** Акт в 600 КБ на слабом канале может качаться полминуты, и зал лучше посмотрит на растущий процент, чем на пропуск (комментарий в `nextAct()`). Пропуск — только если буфер стоит 15 с или прошло 90 с.
- **Интро держит канал.** Акт 1 начинают качать ещё в меню (`prime()`), и пока он качается, пакет звука дека (1.7 МБ) и фоновые записи ждут — первое, что слышит зал, не делит полосу. Если интро уже идёт, канал отдаётся только с акта 4, когда все акты скачаны или качаются (комментарий у `releaseLink()`). Ограничение 9 с в `prime()` не даёт держать голос дека в заложниках. Причина — слабый интернет на телефонах жюри.
- **Предзагрузка старого языка обрывается.** `preload()` при новом URL снимает `src` у прежнего элемента: недокачанный русский акт 1 после переключения на английский съедал бы канал, и английский стартовал бы с холодной загрузки прямо под сторожа (комментарий у `prime()`).
- **Отказ браузера в звуке — внутри фикции.** Обычно жест уже был (клик «НОВАЯ ИГРА»), но если браузер всё равно отказал, интро просит «принять трансляцию» одной клавишей, а не показывает отдельный экран «нажмите для старта» (шапка `16-jury-intro.js`).
- **Интро на SVG и CSS, без WebGL.** Так оно не трогает GL-контекст демки и её разбор задач (шапка `16-jury-intro.js`).
- **Студия пишет только с этой машины.** `serve.js` слушает все интерфейсы, чтобы дек открывался с ноутбука жюри и телефонов, но `studio.html` и все пишущие маршруты отвечают только на запросы с самой машины ([server.md](server.md)). Студия дополнительно проверяет `info.local` и без него не рисует ничего.
- **Одна реплика — один файл.** `saveTake()` сначала стирает все файлы этой реплики с любым звуковым расширением: иначе старый `.mp3` и новый `.webm` лежали бы рядом, и `scanTakes()` выбирал бы между ними по `mtime`.
- **Студия проверяет файл тем же браузером.** Пробный `<audio>` в `attach()`: если браузер не открыл файл, его не откроет и игра (текст сообщения в коде). Вероятно, ещё и потому, что проверка на сервере потребовала бы ffmpeg, который для записи не обязателен.
- **ZIP без сжатия и без npm.** Звук уже сжат, deflate ничего не выиграл бы; ZIP32 с флагом UTF-8 в именах понимают Проводник, Архиватор macOS и 7-Zip (шапка `voice/zip.js`). Зависимостей у проекта нет вовсе.
- **`texts.tsv` с BOM.** Без него Excel читает UTF-8 TSV как cp1251 (комментарий в `packEntries()`).
- **Двойной клик по «▶ сейчас в игре» не считается ошибкой.** Второй клик останавливает первый плеер раньше, чем тот начал играть, и браузер отклоняет первый `play()` с `AbortError`. Это действие самой студии, а не битый файл, поэтому `play()` возвращает `"superseded"`, а не ошибку; второй клик в первые 400 мс трактуется как «играть», а не «стоп» (`playNow()`).
- **Исходники игры читаются через `vm`, с кешем.** Комментарий у `cached()` объясняет кеш размером `08-alice-lines.js` — 1.7 МБ base64. Сейчас этот файл 4.8 КБ (звук уехал в `08b-alice-audio.js`), но 1.7 МБ весит пакет `08b`, который читает `bundle()` через тот же кеш. Кеш по `mtime`+`size` ловит правки из любого источника: студии, командной строки, редактора.

Вложенные:

- **`cleanup()`** — [:120](../../js/core/15-voice-media.js#L120). Останавливает опрос громкости, отключает узлы графа.
- **`finish(kind, err)`** — [:124](../../js/core/15-voice-media.js#L124). Срабатывает один раз (`dead`): `cleanup`, убрать из `active`, `setHold(false)`, `VoiceBus.releaseIf("sample")`, затем `onEnd` для `"end"` или `onError(err)` для `"error"`. Для `"stop"` колбэков нет.
- **`stop()`** — [:134](../../js/core/15-voice-media.js#L134). Пауза и `finish("stop")`. Его же `VoiceBus` вызывает, когда дорожку перебивают.
- **`pause()`**, **`resume()`** — [:138](../../js/core/15-voice-media.js#L138). Пауза и продолжение без освобождения шины; отказ `play()` проглатывается.
- **`follow()`** — [:147](../../js/core/15-voice-media.js#L147). Только при `opts.followLocale`. Пересчитывает `sources(id)`; если первый URL новый — переключает тот же элемент на него, продолжает с той же доли длины (по `loadedmetadata`), продолжает играть, если играл. `attempt = 1`, `switching = true`: ошибка нового источника уводит вниз по новому списку.
- **`route(el)`** — [:162](../../js/core/15-voice-media.js#L162). По http, при работающем `AudioContext`: `MediaElementSource` (один на элемент, `el.__vmSrc`) → `AnalyserNode` (`fftSize` 512, сглаживание 0.6) → `GainNode` → голосовая шина или `ctx.destination`. Усиление: `trim` на голосовой шине (громкость несёт сама шина), `trim × volMaster` на мастере с опросом 200 мс. `el.volume = 1`. Иначе (или при исключении) — `el.volume = trim × busVolume(bus)` и тот же опрос раз в 200 мс. Перед проверкой зовёт `Audio.resume()`, но не ждёт его: если контекст ещё не `running`, дорожка идёт без графа.
- **`tryNext()`** — [:189](../../js/core/15-voice-media.js#L189). Источники кончились → `finish("error", "не удалось загрузить <id>")`. Иначе: берёт элемент из `warm`, если URL совпал и предзагрузка не упала (`!w.error`), или создаёт новый (чужую предзагрузку обрывает). Неудача элемента — вложенная `fail(why)`: срабатывает один раз на элемент (`failed`) и только пока элемент текущий (`el === a`), пишет причину в `h.skipped` (`"EN: …"`, `"EN (повтор): …"`) и в консоль (`[VoiceMedia] …`) и переходит к следующему источнику. Раньше источник, который не грузится, сообщал о себе дважды — событием `error` и отказом `play()` — и каждый звал `tryNext()`: следующий источник пропускался не сыгранным (повтор или целый следующий язык), а поздняя ошибка уже брошенного элемента тоже двигала список. Отказ `play()`: `NotAllowedError` → `finish("error", err)`, другое до старта → следующий источник.
- **`level()`** → 0..1 — [:226](../../js/core/15-voice-media.js#L226). С графом: RMS по временному окну анализатора в дБFS, шкала −48…0 → 0…1 (речь ложится в середину). ## Подводные камни

- **Сгенерированные файлы перезаписываются целиком.** Ручная правка `00-voice-clips.js`, `00-voice-text.js` или `14-jury-cues.js` пропадёт при следующем сохранении в студии, старте `serve.js` (манифест) или `node voice/cues.js`. `00-voice-clips.js` пересобирается и при каждом старте сервера.
- **Порядок реплик сценария — это постановка.** `stagingFor()` ссылается на индексы реплик (`turn: 0…2`) и позиции фраз (`last`, `penult`). Перевод с другим числом реплик или другим порядком говорящих оставит часть сцен несработавшими; в акте 4 «языки» и «№ 410» требуют, чтобы в реплике Нейкона было не меньше двух фраз. Кнопку входа спасает только `armEnter()` после последнего акта.
- **Сценарий длинной дорожки на русском обязателен.** Это база субтитров и запасных таймингов: `setText` не даёт сохранить пустой.
- **Говорящий — только из списка.** `checkScript()` и `SPEAKER` в `cues.js` — два одинаковых списка в двух файлах; новое имя добавлять в оба.
- **`MediaElementSource` создаётся один раз на элемент.** Второй вызов для того же `<audio>` бросает исключение; поэтому источник хранится в `el.__vmSrc`, а `follow()` меняет `src` у того же элемента, не пересоздавая граф.
- **Контекст Web Audio, не успевший проснуться, отправляет дорожку мимо графа.** `route()` зовёт `Audio.resume()`, но не ждёт. Если в этот момент `AudioContext` не `running`, дорожка играет на громкости элемента, анализатора нет, и `level()`/`spectrum()` рисуют поддельную огибающую до конца дорожки.
- **Громкость в обход графа учитывает «звуковые эффекты: выкл», граф — нет.** `busVolume("voice")` → `voiceVolume01()` возвращает 0 при `sfxOn === false`; голосовая шина Web Audio от `sfxOn` не зависит. С `file://` (или без проснувшегося контекста) выключенные эффекты глушат интро и тест, по http — нет. По коду видно, что это расхождение двух путей, а не задуманное правило.
- **Неудачная смена языка начинает дорожку сначала.** Если после `follow()` новый источник не загрузился, `tryNext()` создаёт новый элемент и играет его с нуля, а не с той же доли.
- **Дорожка, которая повисла в загрузке, держит `__voiceMediaHold`.** У интро есть сторож, у теста и пасхалки нет: пока их не остановят кнопкой, реплики дека молчат.
- **`hold` — счётчик.** `setHold(true)` и `finish()` должны идти парами; `finish` защищён флагом `dead`. Любой новый путь завершения дорожки — только через `finish`.
- **Субтитры привязаны к языку старта.** `JuryIntro` не зовёт `follow`; смена языка во время интро меняет только следующие акты (их источник берётся заново в `nextAct`).
- **Колбэки старого акта.** `onStart`/`onEnd`/`onError` проверяют `r.act === myAct`; без этой проверки поздний `ended` пропущенного акта перепрыгнул бы через следующий.
- **Слушатель жеста может пережить интро.** Если в режиме «примите трансляцию» нажать ESC или «Пропустить», `go` остаётся на `window` до первой клавиши; тогда он снимет себя и ничего не сделает (`nextAct` видит `r.done`). Безвредно, но слушатель висит.
- **`dur` в `JURY_CUES` чуть короче записи.** `frames()` не разбирает последние `FRAME + MAXLAG` отсчётов (≈ 44 мс), а `dur = кадры × STEP`. На масштабирование `cuesFor()` это почти не влияет.
- **«▶ сейчас в игре» у длинной дорожки на чужом языке играет русский мастер.** `listing()` ставит `baked` для любой `media` с мастером, а игра (`sources()`) сначала взяла бы русскую запись из студии (`VOICE_CLIPS.ru`), если она есть. Пока русских записей в студии нет, разницы нет.
- **Пересборка субтитров синхронная.** `retime()` → `cues.rebuild()` → `execFileSync("ffmpeg")` внутри обработчика запроса: на секунду-две на трек `serve.js` не отвечает никому, включая телефоны жюри. Сохранять акты во время показа не стоит.
- **Вшитый манифест растёт с каждой записью.** В режиме base64 каждое сохранение кодирует все записи заново: при 25 МБ звука файл скрипта — около 34 МБ, и дек грузит его целиком до первого кадра. Для работы — пути, для флешки — вшить перед раздачей.
- **Живой манифест видит файлы, скопированные руками, сразу.** `GET /api/voice/manifest` сканирует `assets/voice/` при каждом запросе, а `00-voice-clips.js` на диске обновится только при старте сервера или сохранении в студии. С `file://` такие файлы не звучат до этого момента.
- **Точечные правки исходников хрупки к форматированию.** `patchStrings()` ищет заголовок блока языка с отступом ровно 8 пробелов; `patchDeckRu()` — строки `text:` по порядку. Переформатирование `10-i18n.js` или перестановка реплик в `08-alice-lines.js` даст 500 при сохранении текста — файл при этом не испортится.
- **`new Audio()` есть только в студии.** В деке `const Audio` из `01-audio.js` закрывает встроенный конструктор, поэтому `VoiceMedia` создаёт элементы через `document.createElement("audio")`. Код из студии в дек без этой замены не переносить.
- **Имена верхнего уровня заняты.** `VOICE_CLIPS`, `VOICE_TEXT`, `JURY_CUES`, `voiceSync`, `voiceSyncRefill`, `voiceSyncInFlight`, `VoiceMedia`, `JuryIntro`, `VoiceExtras` — повторный `const`/`let` с таким именем в другом файле сломает загрузку.
- **В английском сценарии герой — «Neykon».** `voice/scripts/en.txt` (строки 8, 9) пишет имя так, вероятно, ради произношения; субтитры берут сценарий дословно, и жюри видит «Neykon» рядом с «Neikon» в переводах дека.
