# Справочник по коду

Здесь описано всё, что написано в проекте: каждая функция, каждая
константа и переменная состояния, как устроен каждый движок и почему он
сделан так, а не иначе. Фреймворков, сборки и npm-зависимостей нет — всё
от WebGL-рендера до QR-кодировщика написано вручную, поэтому и описано
вручную.

Общая картина и история решений — в [ARCHITECTURE.md](../ARCHITECTURE.md),
устройство игры для жюри — в [GAME.md](../GAME.md). Этот справочник — уровнем
ниже: открывается рядом с кодом.

## Одна общая область видимости

Браузерная часть — 24 обычных `<script defer>`, не ES-модули. Модули не
грузятся со страницы, открытой двойным кликом (`file://`), а питч должен
открываться и с флешки. Отсюда правила, на которых держится весь код:

1. **Все файлы делят одну глобальную лексическую область.** `const VoiceMedia`
   из `15-voice-media.js` виден в `16-jury-intro.js` без импорта.
2. **Порядок важен только на верхнем уровне.** Скрипт выполняется целиком, прежде
   чем начнётся следующий. Код верхнего уровня может трогать только то, что
   объявлено выше по порядку; внутри функций, вызванных позже (по событию, по
   таймеру, после `DOMContentLoaded`), доступно всё.
3. **Обращение к имени из более позднего файла — через `typeof X !== "undefined"`.**
   `bootEverything()` в `11-settings.js` вызывается прямо во время выполнения этого
   файла, когда `15…21` ещё не загружены: без проверки — `ReferenceError`.
4. **Повторный `const`/`let` с тем же именем в другом файле ломает страницу**
   (`SyntaxError` при загрузке второго файла — он не выполнится вовсе). Новое имя
   верхнего уровня сначала ищется grep'ом по `js/`.
5. **Повторное `function` с тем же именем ошибки не даёт — побеждает последнее.**
   Сейчас так с `escapeHtml`: объявлена в [09-alice-stream.js:35](../../js/presentation/09-alice-stream.js#L35)
   (экранирует и `'`) и в [11-settings.js:496](../../js/core/11-settings.js#L496)
   (не экранирует `'`). Работает вторая — везде, включая сам `09`. Правка первой
   ни на что не влияет.
6. **Модули с состоянием завёрнуты в IIFE** (`const VoiceMedia = (function () {…})()`):
   наружу — один объект, внутренние имена не конфликтуют.

## Словарь

| Слово | Что значит в коде |
|---|---|
| ведущий | Тот, кто показывает питч с компьютера, на котором запущен `serve.js`. Для сервера — запрос с этой машины (`isLocal`) |
| гость | Телефон жюри в той же сети, пришедший по QR. Для сервера — частный адрес (`isLan`), с лимитами |
| запись, дубль (take) | Файл `assets/voice/<язык>/<id>.mp3`, записанный или приложенный в студии |
| id реплики | Имя записи: `deck.slide01`, `deck.bg07`, `jury_act3`, `voice_test`, `secret_locked` |
| длинная дорожка | Акты интро, тест голоса, «Взаперти» — играют через `VoiceMedia` |
| акт | Одна из пяти дорожек интро для жюри |
| cue | Фраза субтитров с временем начала и конца и говорящим (`JURY_CUES`) |
| реплика (turn) | Непрерывный кусок речи одного говорящего; сцены интро привязаны к ним |
| LUCIDITY | Ясность Элис 0–100 %, которую выставляет модель в полигоне |
| VoidOS | Вымышленная ОС в демке: файлы, задачи, мир |
| тракт | Звуковой путь голоса; «тест акустического тракта» — тест голоса в настройках |
| канал | Сетевое соединение браузера; «интро держит канал» — остальная загрузка ждёт |
| локаль | `ru`, `en`, `tj` (литературный таджикский), `tj_col` (разговорный) |

Главный герой — НЕЙКОН (NEIKON). Нейтон — другой персонаж.

## Как держать справочник полным

Полнота проверяется скриптом: он выписывает каждую именованную функцию и
каждую переменную уровня файла/модуля и ищет её имя в странице справочника.

```
node tools/doc-coverage.js --all
```

Добавил функцию — добавь её описание; скрипт покажет, что пропущено. Новый
файл — допиши его в карту `PAGES` в начале скрипта. Скрипт ловит только
забытое: имя, упомянутое мимоходом, он засчитает как описанное.
