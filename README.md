# TERMINAL: SHATTERED — играбельный питч

Презентация проекта, которая сама является демоверсией игры. Открывается
в браузере, работает офлайн, ничего не требует установить.

```bash
python -m http.server 8000
```

Затем `http://localhost:8000`. Можно и просто открыть `index.html`
двойным кликом — скрипты подключены обычными `<script src>`, а не
модулями, поэтому `file://` тоже работает.

## Что внутри

Шесть слайдов о том, почему обучение C++ мертво, и **играбельная демка**
на слайде 02. Демка — не запись: жюри просыпается от первого лица в
пустом пространстве, само доходит до терминала, включает его, смотрит
загрузку ОС и дальше работает в этой ОС.

Четыре языка: русский, английский, таджикский литературный и
таджикский разговорный. Переключается в «НАСТРОЙКИ → СИСТЕМА»,
на лету — включая содержимое файлов внутри игры.

## Файлы

```
index.html          разметка: слайды, стадии демки, чек-лист жюри
styles.css          все стили, включая мобильную адаптацию
js/core/            общее для слайдов и демки: звук, i18n, настройки, мобильный слой
js/presentation/    сам питч — слайды, голос Элис в шапке
js/demo/            игра за терминалом — 3D, VoidOS, задачи, концовки
assets/             QR-код на демку
docs/               архитектура и справочник по игре
```

Скрипты в `js/` пронумерованы и грузятся строго в этом порядке — это
не косметика, порядок важен. Три подпапки — `core/`, `presentation/`,
`demo/` — организационные: `defer` держит порядок по позиции
`<script>`-тега, а не по папке, так что раскладка ничего не меняет
в поведении. Она нужна, чтобы `js/demo/` можно было целиком скопировать
и отдать отдельно — например, на ревью текста игры, без слайдов и без
2.7 МБ base64-аудио из `08-alice-lines.js`. Подробности в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

| файл | папка | о чём |
|---|---|---|
| `01-audio.js` | core | звук на Web Audio, всё синтезируется, файлов нет |
| `02-slides.js` | presentation | шесть слайдов на четырёх языках |
| `03-alice-voice.js` | demo | синтез речи, когда нет подходящей записи |
| `04-void-scene.js` | demo | WebGL: пустота, дверь, пилоны, то что ходит |
| `05-void-os.js` | demo | VoidOS — файловая система, которая и есть уровень |
| `06-demo.js` | demo | стадии демки, оконный менеджер, приложения, починка |
| `07-deck.js` | presentation | роутер слайдов, счётчики в шапке |
| `08-alice-lines.js` | presentation | записи голоса Элис в base64 (2.7 МБ, открывать незачем) |
| `09-alice-stream.js` | presentation | живой канал Элис на слайдах |
| `10-i18n.js` | core | строки интерфейса + переключение языка |
| `11-settings.js` | core | настройки, попапы, экран загрузки |
| `12-jury.js` | demo | чек-лист для жюри |
| `13-mobile.js` | core | адаптация под телефон: клавиатура, свайпы, джойстик |

## Демка за 60 секунд

Слайд 02 → **▶ ЗАПУСТИТЬ ДЕМО-ИГРУ** → выбрать сложность →
дойти до терминала (`WASD` + мышь, на телефоне джойстик и свайп) →
`E` → загрузка ОС → рабочий стол.

Дальше см. [docs/GAME.md](docs/GAME.md) — там разбор всего, что можно
сделать, и как это меняет пространство вокруг.

## Правки

Чаще всего нужно одно из трёх:

- **текст слайдов** — `js/presentation/02-slides.js`, объект `SLIDES_BY_LOCALE`;
- **текст внутри игры** (readme, записки, man, вывод команд) —
  `js/demo/05-void-os.js`, объект `OS_TEXT_BY_LOCALE`;
- **подписи интерфейса** — `js/core/10-i18n.js`, объект `STRINGS`.

Во всех трёх ключи должны совпадать во всех четырёх локалях. Проверить:

```bash
node -e "const s=require('fs').readFileSync('js/core/10-i18n.js','utf8');const i=s.indexOf('const STRINGS');eval(s.slice(i,s.indexOf('function t(')).replace('const STRINGS','var S'));const ru=Object.keys(S.ru);for(const k of Object.keys(S))console.log(k,Object.keys(S[k]).length,ru.every(x=>S[k][x]!==undefined)?'ok':'MISSING')"
```
