```
     дар конфиг як байт мепартоӣ — пушти сарат плита бо ғулғула меҷунбад.
  2. элис ба хотири ман хомӯш. ман бо даст ба ҳаста даромадам ва ӯро даррондам.
     журналҳоро ёб, то ин киса тамоман пахш нашудагӣ.

                                  — худи ту, панҷ дақиқа пеш аз хомӯшӣ
```

## Вазифаҳо: аксуламали хона ва маслиҳат

### room-lamp — чароғи шимолро бедор кун

_Аксуламал ба таъмир:_ тарақкаси хушки реле. чароғи шифт милт кард, як даста шарора туф кард ва мизро бо сафедӣ пур кард. дар атроф як минтақаи кӯр камтар шуд.

- маслиҳат: конфиг аз боло ба поён хонда мешавад. як сатр ба ҳамаи дигараш зид.
- барои ҳакамон: Ин настройкаи чароғ. Ҳар сатр — `параметр = қиймат`. Сатреро ёб, ки чароғ дар он `disabled` (хомӯш) аст, ва `enabled` кун. Дигар чизе даст нарасон. ▶ ИҶРО.

### room-fog — ҳаворо тоза кун

_Аксуламал ба таъмир:_ панҷараи вентилятсия зӯзид ва буғро ба худ кашид. туман нишаст. бори аввал девори рӯбарӯи толорро мебинам — ва аз рӯи хароши плитаи зиреҳӣ, беҳтараш дар туман мемонд.

**Python**
- маслиҳат: филтр аз рӯи таъриф чизеро мегирад. бин, сатри дохили давр бо зичӣ чӣ мекунад.
- барои ҳакамон: Се филтр кор мекунад, ҳар яке бояд 0.03 ғуборро **гирад**. Дар `density = density + 0.03` плюс истодагӣ — филтрҳо зиёд мекунанд. `+`-ро `-` кун. Як аломат. ▶ ИҶРО.

**C++**
- маслиҳат: филтр аз рӯи таъриф чизеро мегирад. бин, сатри дохили давр бо зичӣ чӣ мекунад.
- барои ҳакамон: Се филтр кор мекунад, ҳар яке бояд 0.03 ғуборро **гирад**. Дар `density = density + 0.03f;` плюс истодагӣ. `+`-ро `-` кун. ▶ ИҶРО.

**C**
