## 1. СИСТЕМАРО ДАҲВАТ КАН

_// параличи автокомплит vs реверс-дебаггинг дар зери фишор_

**Автокомплит кодро тезтар менависад, назар ба он ки студент онро хонда расад.** Курсовой аз подсказкаҳо ҷамъ мешавад, лоиҳа аз бори якум компилятсия мешавад, диплом ҳимоя шуд. Баъд ҳамон одам бори аввал `SIGSEGV`-ро дар модули бегонаи 40 ҳазорсатрӣ мебинад — ва ягон усул надорад. На gdb, на core dump, на гипотеза. Tab-ро мезанад ва мунтазир аст, ки касе подсказка диҳад.

Мо инро **параличи автокомплит** меномем: маҳорати код навиштан ҳаст, маҳорати код хондан нест. Маҳорати муқобилаш — **реверс-дебаггинг дар зери фишор**: коди бегонаи шикастаро гирӣ, гипотеза созӣ, санҷӣ ва ба паника наравӣ. Маҳз ҳаминро дар кори якум мепурсанд ва дар ягон донишгоҳ намедиҳанд.

- «компилятсия шуд-ку, пас кор мекунад»
- аввалин segfault-и ҳақиқӣ — аллакай дар прод, соати сеи шаб

### Қайди маърӯзачӣ

#### эзоҳи гӯянда :: оғоз

**Ҷумлаи аввал:** «Аз ҷун пурсед функсия нависад — дар як дақиқа менависад. Коди бегонаи шикастаро диҳед — менишинад ва нигоҳ карда мемонад».

**Панели чапро нишон деҳ:** тамоми ҷавобе, ки студент имрӯз мегирад, ҳамин аст. Як сатр. На сабаб, на қадами оянда.

**Ростро нишон деҳ:** ҳамон хато дар мо. Нур хомӯш шуд, дар давра ба давра бор шуд, компилятор сатр ва сабабро гуфт.

**Тезисе, ки бояд бо худ баранд:** мо код навиштанро намеомӯзонем. Инро автокомплит аллакай кард. Мо коди бегонаи шикастаро _хондан_ меомӯзонем — ягона маҳорат, ки автокомплит онро намепӯшонад.

_Агар пурсанд «ин чаро бозӣ барои бозӣ не»:_ слайди 05, дашбоард барои донишгоҳ. Тайёр нигоҳ дор.

## 2. ДОНИШҲОИ АСОСӢ МУРДАНД

_// ДИАГНОЗ: ҳама аз генератори код вобаста шудаанд_

**Код тезтар пайдо мешавад, назар ба он ки фаҳмиш пайдо шавад.** Tab-ро задӣ — функсияи кории тайёр гирифтӣ. Ҷамъ шуд, тестҳо сабз, корро қабул карданд. Саволи «чаро ин кор мекунад» ягон бор дода нашуд — ва он рӯз, ки ин аз кор мемонад, ин саволро додан дер аст ва ба касе ҳам не.

Мафҳумҳое, ки студентҳо аз китоб «медонанд», вале _ҳис намекунанд_:

```
// глоссарий :: дар таги варта чӣ ҳаст

 │   POINTER    │   │ MEMORY LEAK  │   │     NULL     │

 │   0xDEADBEEF │   │   ▒▒▓▓██▓▓   │   │   ───────►   │
 │   addr lost  │   │   void grows │   │    crash     │

```

### Қайди маърӯзачӣ

#### эзоҳи гӯянда :: диагноз

**Оид ба рақамҳо худат пеш аз савол гӯй:** ин оценкаи мо аз опросҳои кушод аст, на таҳқиқоти мо. Тартиби бузургӣ муҳим, дақиқияш не.

**Фикри асосӣ:** мушкилӣ дар он не, ки студентҳо АИ-ро истифода мебаранд. Истифода бурдан лозим. Мушкилӣ дар он аст, ки ягона машқе, ки маҷбур мекард фаҳмӣ — дебаг кардани хатои худат — гум шуд.

**Агар дар зал устод бошад:** пурс, ки дар курсаш чанд соат ба хондани коди бегона ҷудо шудааст. Ҷавоб қариб ҳамеша — ҳеҷ. Ҳамин сӯрохист, ки мо ба он медароем.

Нагӯй «тарс беҳтарин устод аст». Гӯй: оқибате, ки чашм мебинад, дар ёд мемонад; сатр дар консол — не.

## 3. ДУШВОРИРО ХУДАТ ИНТИХОБ МЕКУНӢ

_// БОЗИНГАР ХУДАШ ҲАЛ МЕКУНАД, ЧӢ ҚАДАР ДОНИСТАН МЕХОҲАД._

**Душворӣ рақами боб не.** Он _бо сатҳ калон намешавад_ — **худи бозингар пеш аз оғоз интихоб мекунад.** Ҳамон як ҳикоя — се хели дидан. Ҳар қадар чуқуртар равӣ, ҳамон қадар тафсилот бисёртар ва подош гаронтар.

Ҳар режим асбобҳои худ ва тарсҳои худро дорад:

```
// ascii :: дар ҳар режим бозингар бо чӣ вомехӯрад
 ┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
 │       EASY       │   │      MEDIUM      │   │       HARD       │
 │      Python      │   │       C++        │   │        C         │
 │   подсказка ҳаст │   │   подсказка баъд │   │   бе подсказка   │
 │   ── сакталӣ нарм│   │   ▒▒ геометрия   │   │   ╳╳ овози Элис  │
 │   ── бе ҷавоб    │   │   ── нимҳақиқат  │   │   ── тамоми ҳақ  │
 └──────────────────┘   └──────────────────┘   └──────────────────┘
```

// пахш кун ва **худат** бозӣ кун — ин _видео не_, ин бозии хурди алоҳида дар браузер. ту **аз шахси якум** дар ҷои холӣ бедор мешавӣ, худат то терминал мерасӣ, боркунии ОС-ро мебинӣ — ва танҳо баъд фармон менависӣ, арвоҳ бошад ба хатоят меоянд.

агар телефон/компютерат TTS дошта бошад — дар HARD Элис зинда гап мезанад. дар EASY/MEDIUM овоз нест, танҳо матн ва глитч.

### Қайди маърӯзачӣ

#### эзоҳи гӯянда :: инро дар саҳна чӣ хел бозӣ кардан

**Мушро деҳ.** «Ин запис ва видео не. Ин бозист, ки аллакай дар ҳамин браузер бор шудааст. Кӣ санҷида мебинад?»

Яке аз жюрӣ (ё худат) **▶ БОЗИИ ДЕМОРО КУШО**-ро пахш мекунад. Презентатсия ба канор меравад, экрани алоҳида кушода мешавад: интихоби душворӣ → _аз шахси якум дар холигӣ бедор шудан_ (дуртар дари глитчдор, дар рост терминал равшан) → бозингар худаш то терминал мерасад ва фурӯзонаш мекунад → боркунии ОС бо ядро ва оболочкаи графикӣ → ва танҳо ҳоло сатри фармон. Бозингар фармон менависад. Хато кунад — экран пора мешавад, арвоҳ мебарояд, дар HARD боз овози Элис бо синтез мешиканад.

**Худат клик накун.** Тамоми таъсир аз ҳамин аст, ки онҳо худашон мешикананд.

**Агар вақт нарасад, ҳатман инро нишон деҳ:** ▶ БОЗИИ ДЕМОРО КУШО-ро пахш кун, ҳеҷ чизро дуруст накарда, — ва нишон деҳ, ки компилятор сатр ва сабабро мегӯяд, хона бошад маҳз ба шакли ҳамон хато мешиканад. Сӣ сония — тамоми маънии маҳсулот.

_Офлайн кор мекунад._ Дар майдон Wi-Fi афтад ҳам — демка инро ҳис ҳам намекунад.

## 5. ТЕРМИНАЛ МУҚОБИЛАТ МЕКУНАД

_// КОДИ ҲИФЗИ ХУДРО ШИКАН_

**Терминал асбоб не. Рақиб аст.** Пеш аз амнезия Нейкон худаш ба модулҳои муҳим қулф гузошт. Ҳоло коди худаш _ӯро ба дарун намемонад_, комментарияҳо дурӯғ мегӯянд, номи тағйирёбандаҳо бошад ҳеҷ маъно надоранд.

Ҳамин аст **реверс-дебаггинг**: на «функсия навис», балки ба системаи бегона бе ягон документатсия даро, фаҳм, ки он дар асл чӣ кор мекунад, ва дуруст кун, боқимондаро нашикаста. Ҳар стажировка аз ҳамин сар мешавад — ва инро дар ягон курс намеомӯзонанд.

// [VOID_CORRUPTED] дар логҳои кӯҳнаи нейкон ёфт шуд
bool verifyAccess(const char* token) {
 unsigned int hash = 0xDEAD;
 while (*token)
 hash ^= (hash << 5) + (*token++) + (hash >> 2);
 return hash == getExpectedHash(); // ← ин функсия нест.
}
// ВАЗИФА: getExpectedHash()-ро тавре нависӣ, ки Элис гузарад.

### Қайди маърӯзачӣ

#### эзоҳи гӯянда :: тарҷума ба забони жюрӣ

**Нагӯй** «қаҳрамони амнезиядор коди худашро ҳак мекунад» — ин ҳамчун сюжети бозӣ садо медиҳад. **Гӯй:** «мо хондани коди кӯҳнаи бегонаро машқ мекунонем — маҳорате, ки кори якум аз он сар мешавад ва дар барнома нест».

**Мисоле, ки медарояд:** масъалаи предохранител. Рақам танҳо дар табличкаи дохили хона ҳаст, ҳар бор аз нав генератсия мешавад, дар файлҳо нест. Дуруст ёфта гирифтан мумкин не, пурсидан ба касе не, генератсия кардан — ҳатто гап нест. Хестан ва нишондодро худат гирифтан лозим.

**Оид ба амнезия — як ҷумла:** ин роҳест, ки «коди бегона»-ро аз худи бозингар созем. Баҳонаи «ба ман лоиҳаи бад доданд» намемонад.

**Агар оид ба риск пурсанд:** асосиаш ин ки донишгоҳ дашбоардро нахарад, розница бошад эпизодро набарорад. Рост ҷавоб деҳ: EP. 0 ройгон аст ва маҳз барои он ҳаст, ки инро пеш аз сарф кардани пули бегона санҷем.
