## 1. ДАҲВАТ БА СИСТЕМА

_// фалаҷи автокомплит vs реверс-дебаггинги зери фишор_

**Автокомплит кодро тезтар менависад, назар ба он ки донишҷӯ онро хонда расад.** Кори курсӣ аз ишораҳо ҷамъ мешавад, лоиҳа бори аввал компилятсия мешавад, диплом ҳимоя мешавад. Баъд одам бори аввал `SIGSEGV`-ро дар модули бегонаи 40 ҳазорсатра мебинад — ва ягон усул надорад. На gdb, на core dump, на фарзия. Ӯ Tab-ро пахш мекунад ва интизори ишора мешавад.

Мо инро **фалаҷи автокомплит** меномем: маҳорати сохтани код ҳаст, маҳорати хондан нест. Маҳорати муқобил — **реверс-дебаггинги зери фишор**: коди бегонаи шикастаро гирифтан, фарзия сохтан, онро санҷидан ва ба ваҳм наафтодан. Маҳз ҳаминро дар кори аввал мепурсанд ва дар ягон донишгоҳ намедиҳанд.

### // ВАЗЪИ ИМРӮЗА :: C++-РО ЧӢ ГУНА МЕОМӮЗОНАНД

```
$ g++ student.cpp -o student
$ ./student

$ _
```

- стек трейсро намехонанд: тамоми функсияро аз нав месозанд
- «компилятсия шуд — пас кор мекунад»
- аввалин segfault-и ҳақиқӣ — аллакай дар прод, соати сеи шаб

- ишорадиҳанда нест: код бегона аст, муаллифаш худи ту то амнезия

### Қайдҳои маърӯзачӣ

#### эзоҳи баромадкунанда :: оғоз

**Ҷумлаи аввал:** «Аз ҷун хоҳиш кунед функсия нависад — дар як дақиқа менависад. Ба ӯ коди бегонаи шикастаро диҳед — менишинад ва нигоҳ мекунад».

**Панели чапро нишон деҳ:** тамоми алоқаи баръакс, ки донишҷӯ имрӯз мегирад, ҳамин аст. Як сатр. На сабаб, на қадами навбатӣ.

**Панели ростро нишон деҳ:** ҳамон як хато дар мо. Рӯшноӣ хомӯш шуд, дар давр зада бор мешавад, компилятор сатр ва сабабро номид.

**Тезисе, ки бояд бо худ баранд:** мо навиштани кодро намеомӯзонем. Инро аллакай автокомплит омӯзонд. Мо _хондани_ коди бегонаи шикастаро меомӯзонем — ягона маҳорате, ки автокомплит онро намепӯшад.

_Агар пурсанд «ин бозӣ барои бозӣ нест-мӣ»:_ слайди 05, дашбоард барои донишгоҳ. Тайёр нигоҳ дор.

## 2. МАРГИ ДОНИШИ АСОСӢ

_// ТАШХИС: эпидемияи вобастагӣ аз ҷенераторҳои худкори код_

**Код тезтар пайдо мешавад, назар ба он ки фаҳмиш ташаккул ёбад.** Tab-ро пахш кардӣ — функсияи кориро гирифтӣ. Он ҷамъ шуд, тестҳо сабз, кор қабул шуд. Саволи «чаро ин кор мекунад» ягон бор дода нашуд — ва дар лаҳзае, ки он аз кор мемонад, ин саволро додан дер аст ва аз касе нест.

Мафҳумҳои калидӣ, ки донишҷӯён аз китоб «медонанд», вале _ҳис намекунанд_:

```

 │   addr lost  │   │   void grows │   │    crash     │
 └──────────────┘   └──────────────┘   └──────────────┘
```

### Қайдҳои маърӯзачӣ

#### эзоҳи баромадкунанда :: ташхис

**Эзоҳ дар бораи рақамҳо — худат пеш аз савол бигӯ:** ин арзёбии мо аз рӯи пурсишҳои кушод аст, на тадқиқоти мо. Тартиби бузургӣ муҳим аст, дақиқӣ — не.

**Фикри асосӣ:** мушкил дар он нест, ки донишҷӯён АИ-ро истифода мебаранд. Истифода бурдан лозим аст. Мушкил дар он аст, ки ягона машқе, ки дар он фаҳмидан лозим меомад — ислоҳи хатои худӣ — нест шуд.

**Агар дар толор омӯзгор бошад:** бипурс, ки дар курси ӯ ба хондани коди бегона чанд вақт ҷудо шудааст. Ҷавоб қариб ҳамеша — ҳеҷ. Ҳамин холигист, ки мо ба он меистем.

Нагӯ «тарс беҳтарин омӯзгор аст». Бигӯ: оқибате, ки дида мешавад, дар ёд мемонад; сатр дар консол — не.

## 3. ИНТИХОБИ ДУШВОРӢ = ИНТИХОБИ НАРХ

_// БОЗИНГАР ХУДАШ ҚАРОР МЕКУНАД, ЧӢ ҚАДАР ОМОДА АСТ ДОНАД._

**Душворӣ ≠ рақами боб.** Он _бо сатҳ намеафзояд_ — онро **худи бозингар пеш аз оғоз интихоб мекунад.** Ҳамон як сюжет — се кадри гуногуни дарк. Ҳар қадар чуқуртар фурӯ равӣ, ҳамон қадар тафсилот бештар ва подош гаронтар.

Ҳар режим маҷмӯи худи асбобҳо ва маҷмӯи худи тарсҳоро медиҳад:

```
// ascii :: бозингар дар ҳар режим бо чӣ рӯ ба рӯ мешавад
 ┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
 │       EASY       │   │      MEDIUM      │   │       HARD       │
 │      Python      │   │       C++        │   │        C         │
 │   ишора кушода   │   │   ишора дертар   │   │   бе ишора       │
 │   ── сакталӣ нарм│   │   ▒▒ геометрия   │   │   ╳╳ овози Элис  │
 │   ── бе ҷавоб    │   │   ── нимҳақиқат  │   │   ── тамоми ҳақ  │
 └──────────────────┘   └──────────────────┘   └──────────────────┘
```

// пахш кун ва **худат** санҷ — ин _сабт нест_, ин бозии хурди алоҳида дар браузер аст. ту **аз шахси якум** дар фазои холӣ ба ҳуш меоӣ, худат то терминал мерасӣ, боркунии ОС-ро мебинӣ — ва танҳо баъд фармон медиҳӣ, арвоҳ бошад ба хатоҳои ту меоянд.

агар дар дастгоҳи ту TTS бошад — дар HARD Элис зинда гап мезанад. дар EASY/MEDIUM овоз намешавад, танҳо матн ва глитчҳо.

### Қайдҳои маърӯзачӣ

#### эзоҳи баромадкунанда :: инро дар саҳна чӣ гуна бозӣ кардан

**Мушро аз даст деҳ.** «Ин сабт нест ва видео нест. Ин бозӣ аст, он аллакай дар ҳамин браузер бор шудааст. Кӣ санҷидан мехоҳад?»

Яке аз аъзои жюрӣ (ё худат) **▶ БОЗИИ ДЕМОРО ОҒОЗ КУН**-ро пахш мекунад. Презентатсия ба канор меравад, экрани алоҳида кушода мешавад: интихоби душворӣ → _бедорӣ аз шахси якум дар холигӣ_ (дар дурдаст дари глитчдор, дар рост терминал месӯзад) → бозингар худаш то терминал мерасад ва онро фурӯзон мекунад → боркунии ОС бо ҳаста ва қабати графикӣ → ва танҳо ҳоло сатри фармон. Бозингар фармон медиҳад. Хато кунад — экран пора мешавад, арвоҳ мебарояд, дар HARD боз овози Элис бо синтези нутқ мешиканад. Ҳамин аст лудонарратив.

**Худат клик накун.** Таъсир маҳз дар он аст, ки онро худи онҳо мешикананд.

**Агар вақт танг бошад, инро ҳатман нишон деҳ:** ҳеҷ чизро ислоҳ накарда, **▶ RUN**-ро пахш кун — ва нишон деҳ, ки компилятор сатр ва сабабро меномад, ҳуҷра бошад дар шакли худи ҳамон хато мешиканад. Сӣ сония, тамоми маънои маҳсул.

_Офлайн кор мекунад._ Агар дар майдонча Wi-Fi афтад — демо инро ҳис ҳам намекунад.

## 5. ТЕРМИНАЛ МУҚОБИЛИЯТ МЕНАМОЯД

_// КОДИ ҲИФЗИ ХУДРО ВАЙРОН КУН_

**Терминал асбоб нест. Рақиб аст.** Пеш аз амнезия Нейкон худаш дастрасиро ба модулҳои критикӣ баст. Ҳоло коди худи ӯ _ӯро ба дарун роҳ намедиҳад_, шарҳҳо дурӯғ мегӯянд, номҳои тағйирёбандаҳо бошад ҳеҷ маъно надоранд.

Маҳз ҳамин аст **реверс-дебаггинг**: на «функсия навиштан», балки ба системаи бегона бе ҳуҷҷатгузорӣ даромадан, фаҳмидан, ки он дар асл чӣ мекунад, ва ислоҳ кардан бе шикастани боқимонда. Ҳар таҷрибаомӯзӣ аз ҳамин оғоз меёбад — ва инро дар ягон курс намеомӯзонанд.

// [VOID_CORRUPTED] дар логҳои кӯҳнаи нейкон ёфт шуд
bool verifyAccess(const char* token) {
 unsigned int hash = 0xDEAD;
 while (*token)
 hash ^= (hash << 5) + (*token++) + (hash >> 2);
 return hash == getExpectedHash(); // ← ин функсия вуҷуд надорад.
}
// ВАЗИФА: getExpectedHash()-ро тавре имплементатсия бикун, ки Элис гузарад.

### Қайдҳои маърӯзачӣ

#### эзоҳи баромадкунанда :: тарҷума ба забони жюрӣ

**Нагӯ** «қаҳрамони амнезиядор коди худашро ҳак мекунад» — ин мисли сюжети бозӣ садо медиҳад. **Бигӯ:** «мо хондани коди мероси бегонаро машқ мекунонем — маҳорате, ки кори аввал аз он оғоз меёбад ва дар барнома нест».

**Мисоле, ки мегирад:** масъалаи предохранитель. Рақам танҳо дар лавҳачаи ҳуҷра ҳаст, дар ҳар корандозӣ аз нав тавлид мешавад, дар файлҳо нест. Интихоб карда наметавонӣ, пурсидан аз касе нест, тавлид кардан — ҳатто бештар не. Хестан ва нишондодро гирифтан лозим.

**Дар бораи амнезия — як ҷумла:** ин роҳи «коди бегона»-ро аз они худи ту кардан аст. Баҳонаи «ба ман лоиҳаи бад доданд» намемонад.

**$18 000 ба куҷо меравад:** овоздиҳӣ ва садо, рассом барои ҳуҷраҳои EP. 1, ҳашт моҳи кори ду нафар. Ба тақсимоти маблағ тайёр бош — қариб ҳамеша мепурсанд.

**B2B дар як ҷумла:** «Бозӣ барои донишгоҳ ройгон аст. Пулро барои дашбоарди метрикаҳои дебаггинг медиҳанд — барои он ки бинанд, гурӯҳ дар куҷо истод, на танҳо кӣ то охир расид».

**Чаро литсензияи ройгон стратегия аст, на саховат:** он харидро бекор мекунад. Омӯзгор метавонад модулро ҳафтаи оянда гузорад, бе буҷа. Пул баъдтар ва аз сатҳи факултет меояд.

**Агар дар бораи хатар пурсанд:** хатари асосӣ — ин ки донишгоҳ дашбоардро нахарад, чакана бошад эпизодро барнагардонад. Рост ҷавоб деҳ: EP. 0 ройгон аст ва барои он вуҷуд дорад, ки инро пеш аз сарф кардани пули бегона санҷем.
