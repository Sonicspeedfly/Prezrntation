# Текст для ревью

Снимок всего player-facing текста проекта, вынутый из кода в читаемые
Markdown-файлы — специально для того, чтобы можно было отдать **только
текст демки** (или только презентации) на отдельную проверку, не
таская с собой WebGL-шейдеры, игровой движок или 2.7 МБ base64-аудио.

Это **копия**, не источник правды. Правки вносятся в код
(`js/presentation/`, `js/demo/`, `js/core/10-i18n.js`), а не в файлы
здесь — при следующем большом текстовом проходе эту папку нужно
перегенерировать заново (см. «Как обновить» ниже).

## Структура

```
text-review/
  export.js     — сборщик: пересобирает всё, что ниже, прямо из кода
  presentation/
    ru.md       — шесть слайдов питча + speaker notes
    en.md
    tj.md
    tj_col.md
  demo/
    ru.md       — документы Нейкона, реплики, реакции, подсказки задач
    en.md
    tj.md
    tj_col.md
```

Один файл = одна локаль = самодостаточный документ, который можно
целиком скопировать в чат другой модели или отправить человеку.

## Что внутри `demo/<locale>.md`

1. **Документы Нейкона (VoidOS)** — readme, три записки, финальная
   записка «note.again», таблички на опорах и приборах, два лога
   (`anchor.log`, `session.log`). Это то, что игрок читает командой
   `cat` за столом — источник данных: `OS_TEXT_BY_LOCALE` +
   `OS_STORY_BY_LOCALE` в `js/demo/05-void-os.js`.
2. **Реплики и реакции** — всё игровое из `STRINGS` в
   `js/core/10-i18n.js`: реакции стола (`demo.desk.*`), пять аномалий
   (`demo.glitch.*`), скример при проигрыше (`demo.scare.*`),
   walkthrough-подсказки для жюри (`demo.walk.*`), четыре типа
   концовки (`demo.end.*`), пробуждение в пустоте (`demo.void.*`).
3. **Задачи** — по каждой из семи задач: реакция комнаты на починку
   (`lore`) и обе подсказки (`hint` техническая, `hintNoob` для жюри)
   на всех трёх синтаксисах (Python / C++ / C). Сам код задач сюда не
   вынесен — он живёт в `TASKS_BY_DIFF` (`LADDER_PY`/`LADDER_CPP`/`LADDER_C`)
   внутри `js/demo/06-demo.js`, и это уже код, а не текст.

## Что внутри `presentation/<locale>.md`

Все шесть слайдов целиком: заголовок, подзаголовок, тело (списки,
callout-блоки, ASCII-иллюстрации, статкарты — всё converted в читаемый
Markdown) и speaker notes под каждым. Источник — `SLIDES_BY_LOCALE` в
`js/presentation/02-slides.js`.

## Как обновить

После любой правки текста в `js/` — пересобрать одной командой:

```
node text-review/export.js
```

Скрипту не нужен ни сервер, ни браузер, ни зависимости: он загружает
`02-slides.js`, `05-void-os.js` и `10-i18n.js` в песочницу `vm` и читает
те же самые объекты, что читает страница. В том числе повторяет
`Object.assign(OS_TEXT_BY_LOCALE, OS_STORY_BY_LOCALE)` — иначе в выгрузку
попал бы мёртвый текст из базовой таблицы, которого игрок не видит.

Автоматически это не запускается, так что после большого текстового
прохода команду нужно выполнить руками — иначе файлы здесь разъедутся
с кодом.
